# PacketZero Board

New security vulnerabilities from the last 30 days, explained two ways: in plain words anyone can follow, and in full technical detail for IT and security teams.

- **Live board:** https://YOUR-USERNAME.github.io/packetzero-board/
- **Data:** `vulns.json`, which covers CISA Known Exploited Vulnerabilities and new critical CVEs, with a source link on every entry.

Each entry has a simple side (what it is, an everyday comparison, who's affected, what to do) and a technical side (flaw class, how it works, affected and fixed versions).

Always check the vendor advisory linked on each entry before acting. This board is for information only.
